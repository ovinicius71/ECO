# Modelo de brainstorm

Copie este modelo para `docs/brainstorm/NN-slug.md` no início de cada parte.

```markdown
# Brainstorm — Parte NN: <título>

Branch: `<tipo>/NN-slug` · Base: `main` | empilhada sobre `<branch>`
Data: AAAA-MM-DD

## Contexto
O que esta parte entrega, em 2–4 linhas. Links para spec/design relevantes.

## Já decidido
- Itens que vêm do CLAUDE.md, das specs ou de ADRs, e que não serão rediscutidos.

## Perguntas bloqueantes (preciso da resposta antes de codar)
1. **Pergunta?**
   - A) opção — consequência
   - B) opção — consequência
   - Recomendação: A, porque …

## Perguntas não bloqueantes (sigo a recomendação se não houver resposta)
1. **Pergunta?** Recomendação: … (motivo)

## Riscos e o que pode dar errado
- …

## Plano de commits
1. `tipo(escopo): …`
2. …

## Decisões (preenchido depois das respostas)
- P1 → B (dono, AAAA-MM-DD)
- NB1 → decidido por padrão
```
